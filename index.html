Why games?

Security stories are usually told with jargon. Here you push the buttons yourself: send the packets, aim the overflow, release the worm, and find the fix.

Who it's for

Anyone. The main path uses plain language and everyday metaphors. "Go deeper" notes add the real technical detail for people who want it.

How it's built

Every case is a single self-contained page with its own design, so each one can look like the world of its story.

An independent educational project, not affiliated with or endorsed by any company, government or organisation named. It contains no exploit code. No cookies, no tracking, no third-party requests. Spot a mistake? Report it on GitHub.

Inspired by explorable explanations such as Nicky Case's The Evolution of Trust.
